# FreeRide Racing · единый Telegram-лаунчер

**Текущий релиз:** [RELEASE_CURRENT.md](RELEASE_CURRENT.md). Публичная точка входа: https://djalilovich097.github.io/FreeRide-NFSU2-Launcher/

Три направления: **Underground 2**, закрытый **Most Wanted (2005)** и read-only **Racing Hub**. Бот `@freeride_team_bot` обеспечивает входы, но движки и сохранения двух игр остаются независимыми.

`main` является поддерживаемой версией. Старые промежуточные материалы: [docs/archive/2026-11](docs/archive/2026-11/).

Публичный GitHub Pages содержит только HTML/CSS/JS. Ни оригинальные игровые файлы EA, ни реальные карьеры, ни секреты Telegram или Supabase туда не помещаются.

Физическая папка: `C:\Users\FreeRide\FreeRide Games\FreeRide-NFSU2-Launcher`. Старый адрес в корне Windows — NTFS-ссылка совместимости.
